## 🎭 Animations & Effets

### Animations Disponibles
```
fade-in          : Apparition en fondu (300ms)
slide-up         : Glissement vers le haut (400ms)
slide-down       : Glissement vers le bas (400ms)
scale-in         : Zoom + fondu (300ms)
slide-in-left    : Glissement gauche (300ms)
```

### Effets Hover
```
Buttons:   scale-105 + shadow-lg
Icons:     scale-110 + color change
Cards:     shadow-xl + translate
Links:     color change + underline
```
